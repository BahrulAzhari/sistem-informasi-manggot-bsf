## tutorial collaborasi
1. git clone https://github.com/BahrulAzhari/sistem-informasi-manggot-bsf
2. cd sistem-informasi-maggot-bsf
3. composer install

## salin .env.example menjadi .env, isi konfigurasi database lokal kalian, lalu jalankan:
1. php artisan key:generate
2. php artisan migrate
3. npm install
4. npm run build
5. php artisan serve
